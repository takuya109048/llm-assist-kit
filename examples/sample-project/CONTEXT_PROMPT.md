# プロジェクト概要
- コマンドラインで使う ToDo 管理ツール。データは JSON ファイルに保存する
- `web/` は同じ JSON を表示するだけの簡易ビューア

# 開発ルール
- Python 3.11+、標準ライブラリのみ(外部依存を追加しない)
- テストは pytest。変更を提案するときはテストも一緒に書く
- 型ヒントを必ず付ける

# 回答のしかた
- 日本語で答える
- コードを変更するときは、ファイルパスと変更後のコード全体を示す
- このメッセージには「了解しました」とだけ返し、次の依頼を待つ
